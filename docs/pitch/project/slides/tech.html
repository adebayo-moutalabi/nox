How we built it

Powered by the OpenAI Realtime API.

Voice

Real-time voice over WebRTC. You can interrupt Nox, like a person.

Actions

Function calling: set a task, start a timer, open an app, take a note.

Speaks first

Events (drift, return, timer, meeting) make Nox talk on its own.

Private by design: the API key never reaches the window (short-lived token), data stays on your PC, and Nox reads only the window title, only with your OK.

How did we build it? With the OpenAI Realtime API. The voice is live, over WebRTC. You can stop Nox when it talks, like with a person. Nox uses function calling to act: create a task, start a timer, open an app. And events make Nox speak first: when you drift, when you come back, when the timer ends. Privacy is important: the key never goes to the window, your data stays on your computer, and Nox only reads the window title, and only if you say yes.
